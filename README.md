Desafio Prático — Análise, Correção e Melhoria do Sistema da Loja
Contextualização
Nas atividades anteriores, foi desenvolvido progressivamente um Sistema de Loja, aplicando os principais fundamentos estudados até o momento.

Agora o objetivo não é simplesmente adicionar uma nova funcionalidade.

Nesta atividade, você deverá assumir o papel de um desenvolvedor responsável por analisar e melhorar um sistema existente.

Você deverá observar seu funcionamento, identificar possíveis problemas, realizar testes, propor correções e implementar melhorias.

Objetivos
Ao final desta atividade, espera-se que o aluno seja capaz de:

analisar um programa já desenvolvido;

compreender o fluxo de execução de uma aplicação;

identificar problemas de lógica;

identificar situações não previstas;

validar informações fornecidas pelo usuário;

aplicar estruturas condicionais;

aplicar estruturas de seleção;

utilizar estruturas de repetição;

testar diferentes cenários;

corrigir comportamentos inadequados;

propor melhorias para uma aplicação existente.
